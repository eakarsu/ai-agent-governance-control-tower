# AI Agent Governance Control Tower Feature Registry

- `agent-registry` - Agent Registry (Governance): Registered agents, owners, purpose, model stack, environments, and deployment status.
- `permission-policies` - Permission Policies (Governance): Tool scopes, data access rules, approval thresholds, and policy exceptions.
- `tool-call-audit` - Tool Call Audit (Audit): Tool calls, inputs, outputs, reviewers, timestamps, and anomaly flags.
- `human-approval-queue` - Human Approval Queue (Controls): Pending approvals, risk level, business impact, reviewer notes, and SLA status.
- `rollback-controls` - Rollback Controls (Controls): Kill switches, rollback plans, disabled tools, incident links, and recovery evidence.
- `agent-risk-scoring` - Agent Risk Scoring (Risk): Autonomy level, data sensitivity, tool exposure, failure history, and risk score.
- `eval-gates` - Eval Gates (Quality): Pre-release eval results, regression checks, safety thresholds, and launch decisions.
- `incident-review` - Incident Review (Risk): Agent incidents, root cause, containment actions, owner follow-up, and audit closeout.
- `compliance-evidence` - Compliance Evidence (Evidence): Policy mappings, screenshots, approvals, eval artifacts, and audit-ready evidence.
- `executive-reporting` - Executive Reporting (Reporting): Board-ready agent risk posture, trends, exceptions, and control coverage.
- `documents` - Documents
- `notifications` - Notifications
- `integrations` - Integrations
- `profiles` - Profiles
- `ai-assistant` - AI Assistant
- `ai-tools` - AI Tools
